# GymTracker

GymTracker is a full-stack application for tracking gym workouts. It allows users to register, log their workouts (type, duration, calories, intensity, and fatigue), and track their weekly progress over time.

## Project Overview

* Frontend: Angular
* Backend: ASP.NET Core (.NET 10) Web API, built with Clean Architecture
* Database: PostgreSQL
* Authentication: JWT with BCrypt password hashing
* API Documentation: Swagger / OpenAPI

## Getting Started

### Prerequisites

* Docker v28.0 or higher
* Docker Compose v1.29.0 or higher
